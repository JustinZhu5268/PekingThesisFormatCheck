# 大标题各类问题总结

## 一、问题描述

用户反馈了以下问题：

### 1. 附录A、致谢显示不全
- **现象**：附录A和致谢的大标题在Word中显示不完整，被页眉遮挡
- **根因**：原始文档中，附录和致谢标题的段落格式设置了异常的间距（`space_before=3pt`，`line_spacing_rule=EXACTLY`）

### 2. 第一到第六章与第七章字体大小不一致
- **现象**：第1-6章标题（绪论~管理保障）的字号是16pt，但结论与展望、参考文献、附录、致谢的字号是"继承"（未显式设置）
- **根因**：当我们在"参考文献/附录/致谢"段落上添加 `<w:numPr><w:numId w:val="0"/></w:numPr>` 来禁用自动编号时，Word创建了新的pPr元素，导致样式继承链中断，字体设置丢失

### 3. 所有章节样式不一致
- **现象**：用户质疑为什么各章节的Heading 1样式不一样
- **解释**：Word的样式是继承的，但当我们修改XML（如禁用编号）时，显式设置的属性会覆盖继承的值，导致不一致

### 4. 章标题自动编号与正文字体不一致（最新问题）
- **现象**："第七章"（自动编号）显示为宋体，而"结论与展望"（标题正文）显示为黑体
- **根因**：Word中"自动编号的字体"和"段落文字的字体"是分离的。Heading 1样式只控制段落文字字体，编号字体由numbering.xml中的模板控制

## 二、修复方案

### 方案一：fix_heading_spacing() - 统一标题段落格式

在 `docx_autofixer.py` 中新增 `fix_heading_spacing()` 函数，统一所有Heading 1段落的格式：

**规则（北大论文格式）**：
- 字体：黑体
- 字号：三号(16pt)
- 对齐：居中
- 行距：单倍行距
- 段前：24pt
- 段后：18pt

```python
def fix_heading_spacing(self):
    """
    统一所有 Heading 1 标题的字体和间距
    规则：黑体，三号(16pt)，居中，单倍行距，段前24磅，段后18磅
    """
    from docx.shared import Pt
    from docx.enum.text import WD_LINE_SPACING, WD_ALIGN_PARAGRAPH
    from docx.oxml.ns import qn
    
    for idx, para in enumerate(self.doc.paragraphs):
        if para.style and 'Heading 1' in para.style.name:
            # 1. 设置居中对齐
            para.alignment = WD_ALIGN_PARAGRAPH.CENTER
            
            # 2. 设置段落间距
            pf = para.paragraph_format
            pf.space_before = Pt(24)
            pf.space_after = Pt(18)
            pf.line_spacing_rule = WD_LINE_SPACING.SINGLE
            
            # 3. 设置字体
            for run in para.runs:
                run.font.size = Pt(16)
                run.font.name = '黑体'
                run._element.rPr.rFonts.set(qn('w:eastAsia'), '黑体')
```

### 方案二：fix_heading1_numbering_font() - 统一编号字体

**问题**：Word的自动编号（如"第七章"）字体与段落文字（如"结论与展望"）字体分离控制。

**修复逻辑**：
1. 从 `Heading 1` 样式定义中获取 `numId`（编号ID）
2. 在 `numbering.xml` 中找到对应的 `abstractNum` 模板
3. 修改第一级标题 (`lvl[@ilvl=0]`) 的字体设置为"黑体"

```python
def fix_heading1_numbering_font(self):
    """
    强制将 Heading 1 (章标题) 的自动编号字体设置为黑体
    """
    # 1. 从样式中获取 Heading 1 的 numId
    for style in self.doc.styles:
        if style.name == 'Heading 1':
            style_elem = style._element
            pPr = style_elem.find(qn('w:pPr'))
            if pPr is not None:
                numPr = pPr.find(qn('w:numPr'))
                if numPr is not None:
                    heading1_numId = numPr.find(qn('w:numId')).get(qn('w:val'))
    
    # 2. 追踪到 numbering.xml 中的模板
    numbering_xml = self.doc.part.numbering_part._element
    num_nodes = numbering_xml.xpath(f'.//w:num[@w:numId="{heading1_numId}"]/w:abstractNumId')
    abstractNumId_val = num_nodes[0].get(qn('w:val'))
    
    # 3. 修改编号字体
    lvl_nodes = numbering_xml.xpath(f'.//w:abstractNum[@w:abstractNumId="{abstractNumId_val}"]/w:lvl[@w:ilvl="0"]')
    lvl_node = lvl_nodes[0]
    
    rPr = lvl_node.find(qn('w:rPr'))
    if rPr is None:
        rPr = OxmlElement('w:rPr')
        lvl_node.insert(0, rPr)
    
    rFonts = rPr.find(qn('w:rFonts'))
    if rFonts is None:
        rFonts = OxmlElement('w:rFonts')
        rPr.append(rFonts)
    
    # 设置为黑体
    rFonts.set(qn('w:ascii'), '黑体')
    rFonts.set(qn('w:eastAsia'), '黑体')
    rFonts.set(qn('w:hAnsi'), '黑体')
    rFonts.set(qn('w:cs'), '黑体')
```

## 三、调用顺序（关键）

在 `fix_all()` 函数中的调用顺序至关重要：

```python
def fix_all(self, output_path=None):
    # ... 前面各种修复 ...
    
    # ★★★ 关键调用顺序 ★★★
    # 1. 先修复编号字体（在禁用编号之前！）
    self.fix_heading1_numbering_font()
    
    # 2. 再禁用参考文献/附录/致谢的自动编号
    self.fix_chapter_tail_numbers()
    
    # 3. 然后统一所有标题样式（覆盖XML修改导致的样式丢失）
    self.fix_heading_spacing()
    
    # 4. 最后其他修复
    self.fix_acknowledgments_punctuation()
    self.fix_caption_colon()
    # ...
```

**为什么顺序重要**：
- `fix_heading1_numbering_font()` 必须在 `fix_chapter_tail_numbers()` **之前**执行
- 因为 `fix_chapter_tail_numbers()` 会禁用编号，禁用后段落就没有 `numPr` 了，无法找到编号模板
- `fix_heading_spacing()` 必须在禁用编号**之后**执行，因为禁用编号会创建新的pPr元素导致样式丢失

## 五、问题根因深入分析

### 1. 为什么附录/致谢标题显示不全？

**原因**：附录和致谢的段落格式中设置了异常的`space_before=3pt`和`line_spacing_rule=EXACTLY`

| 章节 | space_before | line_spacing |
|-----|-------------|--------------|
| 绪论~管理保障 | 24.0 pt | 1.0 (1.5倍) |
| 结论与展望 | None | None |
| **参考文献** | None | None |
| **附录** | **3.0 pt** | **203200 (极小!)** |
| **致谢** | **3.0 pt** | **203200 (极小!)** |

当段前间距只有3pt时，标题距离页眉太近，被遮挡。

### 2. 为什么第1-6章与第7章/参考文献/附录/致谢字号不一致？

**原因**：当我们修改XML添加 `<w:numPr><w:numId w:val="0"/></w:numPr>` 来禁用自动编号时，创建了新的pPr元素，导致样式继承链中断。

### 3. 为什么自动编号和正文字体不一致？

**原因**：Word中样式系统分离：
- 段落文字字体：由 `Heading 1` 样式控制
- 编号字体：由 `numbering.xml` 中的 `abstractNum` 模板控制

两者独立，需要分别修改。
